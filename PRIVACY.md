# LecturaBot Privacy Policy

**Last updated:** July 29, 2026

By using LecturaBot, you agree to this privacy policy.

## What data does LecturaBot store?

LecturaBot stores only the data it needs to run reading sessions and restore
them after a restart. This may include:

- Discord user IDs and display names for queues, corrections, and reading
  statistics
- Server, channel, and message IDs used to keep each session connected to the
  correct Discord messages and voice channel
- Active queue and reading-session state
- Custom reading text and submitted corrections while they are part of an
  active session
- Completed-turn counts, total reading time, and the time of the most recent
  completed turn

LecturaBot does not sell user data or use it for advertising.

## Where is the data stored?

The bot stores its data in a private SQLite database on the server where it
runs. Access is limited to the bot operator and people responsible for
maintaining that server.

Messages and embeds posted by the bot are also stored by Discord according to
Discord's own policies. Server moderators may be able to view or delete those
messages independently of LecturaBot.

## How long is it kept?

Active-session data is updated as people join, leave, read, or submit
corrections. Reading statistics are retained so the bot can show recent turn
counts and averages. Database backups may temporarily retain older copies.

## Questions or deletion requests

If you have a privacy question or want data associated with your Discord
account reviewed or deleted, contact **ryry013** on Discord. Please include your
Discord user ID so the correct records can be identified.

Some content posted in a Discord channel may need to be removed separately by a
server moderator.
